# Inputs Panel Implementation Plan (PR B)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a reader change the model's assumptions and watch every number re-answer, without any price silently becoming wrong.

**Architecture:** The cost engine already runs in the browser (PR A). This plan makes `INPUTS` mutable, re-runs `compute()` on change, and teaches `buyPrice` to scale an observed price along the retention curve when the buy odometer moves away from the mileage that price was measured at. The existing static eyebrow becomes a live summary strip that expands into the fields.

**Tech Stack:** Plain ES5 JavaScript (page and engine), Python 3.8+ stdlib (build and tests), Node 20+ (tests only).

## Global Constraints

- The published page keeps **zero runtime dependencies**. Node is dev-only.
- `index.html` stays **ES5**: `var` and `function` only. The sole exception is the grandfathered `const MODELS`.
- **No rounding inside `engine.js`.** Round only at display.
- `python3 test_build.py` remains the single test entry point.
- **`data/engine-fixture.json` must not be regenerated by this plan.** Every change here is a no-op at default inputs — verified: all four observed prices are anchored at 40,000 miles, which equals `buy_odometer`, so the scaling factor is exactly 1.0. If a task makes the parity test fail, the task is wrong, not the fixture. This also keeps issue #18 untriggered.
- Validation is **fail-closed**: an invalid input must never reach the cost function. `annual_miles` of 0 divides by zero; a negative odometer produces a nonsense retention index.

/* Price scaling. An observed price is measured at one odometer reading;
   moving the buy point must move the price along the retention curve, or the
   page shows a 40,000-mile price against a 70,000-mile buy point. */
const scaled = models.find(m => m.observedPrice);
if (!scaled) throw new Error('no observed-price vehicle to test scaling against');

const atAnchor = VA.buyPrice(scaled, inputs);
if (atAnchor.price !== scaled.observedPrice || atAnchor.basis !== 'observed') {
  throw new Error(`at its own anchor a price must be returned untouched and marked observed, got ${JSON.stringify(atAnchor)}`);
}

const moved = VA.buyPrice(scaled, { ...inputs, buy_odometer: 70000 });
const expected = scaled.observedPrice
  * VA.retentionIndex(70000, inputs.retention_anchors)
  / VA.retentionIndex(scaled.observedAt, inputs.retention_anchors);
if (Math.abs(moved.price - expected) > 1e-9) {
  throw new Error(`scaled price ${moved.price} != ${expected}`);
}
if (moved.basis !== 'derived') {
  throw new Error(`a scaled price must be marked derived, got ${moved.basis}`);
}
if (!(moved.price < scaled.observedPrice)) {
  throw new Error('a higher-mileage buy point must cost less');
}
console.log('ok: observed prices scale along the retention curve');

- [ ] **Step 3: Implement the scaling**

Replace `buyPrice` in `engine.js`:

```javascript
  function buyPrice(v, inp) {
    if (v.observedPrice) {
      /* Scale along this vehicle's own curve from a measured point. No
         resaleMultiplier is involved -- that is what made the retired MSRP
         derivation double-penalise fast-depreciating models. At the anchor
         the ratio is exactly 1 and the observed figure passes through. */
      if (v.observedAt && v.observedAt !== inp.buy_odometer) {
        var ratio = retentionIndex(inp.buy_odometer, inp.retention_anchors)
                  / retentionIndex(v.observedAt, inp.retention_anchors);
        return { price: v.observedPrice * ratio, basis: 'derived' };
      }
      return { price: v.observedPrice, basis: 'observed' };
    }
    return { price: v.price, basis: 'placeholder' };
  }
```

- [ ] **Step 3: Write validation and wiring**

```javascript
function fieldValid(f,n){
  if(!isFinite(n)||n<f.min||n>f.max)return false;
  /* A cycle must run forwards, or cycle miles go negative and every
     per-mile figure inverts. */
  if(f.k==="buy_odometer"&&n>=INPUTS.sell_odometer)return false;
  if(f.k==="sell_odometer"&&n<=INPUTS.buy_odometer)return false;
  return true;
}
function applyInput(f,el){
  var n=parseFloat(el.value);
  if(!fieldValid(f,n)){el.setAttribute("aria-invalid","true");return false}
  el.removeAttribute("aria-invalid");
  INPUTS[f.k]=n; return true;
}
function inputsChanged(){
  for(var i=0;i<FIELDS.length;i++){var k=FIELDS[i].k; if(INPUTS[k]!==DEFAULTS[k])return true}
  return false;
}
function summaryText(){
  return Math.round(INPUTS.annual_miles).toLocaleString()+" mi/yr · buy at "
    +Math.round(INPUTS.buy_odometer/1000)+"k · sell at "
    +Math.round(INPUTS.sell_odometer/1000)+"k · gas $"+INPUTS.gas_per_gal.toFixed(2)
    +(inputsChanged()?" · edited":"")+" — change";
}
function drawFields(){
  ["Rank","Flat"].forEach(function(g){
    document.getElementById("fields"+g).innerHTML=FIELDS.filter(function(f){
      return f.rank===(g==="Rank")}).map(function(f){
      return '<div><label for="f_'+f.k+'">'+esc(f.l)+'</label>'
        +'<input id="f_'+f.k+'" type="number" inputmode="decimal" step="'+f.step
        +'" min="'+f.min+'" max="'+f.max+'" value="'+INPUTS[f.k]+'"></div>'}).join("");
  });
  FIELDS.forEach(function(f){
    document.getElementById("f_"+f.k).addEventListener("input",function(e){
      if(applyInput(f,e.target))render();
    });
  });
}
```

- [ ] **Step 1: Implement**

```javascript
function writeHash(){
  var p=[];
  FIELDS.forEach(function(f){if(INPUTS[f.k]!==DEFAULTS[f.k])p.push(f.k+"="+INPUTS[f.k])});
  if(W.join(",")!=="25,15,15,10,20,15")p.push("w="+W.join(","));
  if(FILT!=="all")p.push("f="+FILT);
  if(SEL)p.push("v="+encodeURIComponent(SEL));
  var h=p.join("&");
  history.replaceState(null,"",h?"#"+h:location.pathname);
}
function readHash(){
  /* A malformed or stale link must land on the defaults rather than a
     half-applied state. Anything unrecognised is dropped silently. */
  var h=location.hash.replace(/^#/,""); if(!h)return;
  h.split("&").forEach(function(kv){
    var i=kv.indexOf("="); if(i<0)return;
    var k=kv.slice(0,i), v=decodeURIComponent(kv.slice(i+1));
    if(k==="w"){var a=v.split(",").map(Number);
      if(a.length===6&&a.every(function(n){return isFinite(n)&&n>=0&&n<=100})){W=a;PRESET="Custom"}
      return}
    if(k==="f"){if(FILTERS.some(function(x){return x.k===v}))FILT=v; return}
    if(k==="v"){if(MODELS.some(function(m){return m.name===v}))SEL=v; return}
    for(var j=0;j<FIELDS.length;j++){
      if(FIELDS[j].k===k){var n=parseFloat(v); if(fieldValid(FIELDS[j],n))INPUTS[k]=n; return}
    }
  });
}
```

Call `readHash()` before the first `drawFields()`/`render()`, and `writeHash()` at the end of `render()`.

**Placeholders.** None. Every step carries its code or command.

The panel ships eleven fields without it. Financing mode, loan APR, and down payment stay out of scope per the spec.
